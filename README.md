# 💡 Automatic Light Control & LDR-Based Relay Switching System

### Analog Light Sensing, Adjustable Threshold Detection & AC Load Control

> A PCB-based automatic light control system designed using EasyEDA. The circuit uses an LDR to sense ambient light, an LM358 comparator for threshold detection, a BC547 transistor for relay driving, and a 5V relay to control an AC bulb automatically.

## 📌 Overview

The system automatically switches an AC bulb based on the surrounding light intensity.

An **LDR (Light Dependent Resistor)** converts changes in ambient light into a varying voltage. An **LM358 comparator** compares this voltage with an adjustable reference voltage set using a potentiometer.

The comparator output drives a **BC547 transistor**, which energizes a **5V relay** to control the connected AC load.

⚙️ Working Principle
1. Light Sensing

The LDR changes its resistance according to the intensity of incident light.

More Light  → Lower LDR Resistance
Less Light → Higher LDR Resistance

The LDR and resistor form a voltage divider that converts the resistance variation into a measurable voltage.

2. Threshold Detection

The LM358 compares the LDR sensing voltage with the reference voltage generated by the potentiometer.

LDR Voltage
     ↓
   LM358
     ↑
Reference Voltage
     ↑
Potentiometer

Changing the potentiometer changes the switching threshold.

3. Relay Switching

The LM358 output controls the BC547 transistor.

LM358
  ↓
BC547
  ↓
Relay Coil
  ↓
Relay Contacts
  ↓
AC Bulb
4. Protection

A 1N4148 flyback diode is connected across the relay coil to suppress the voltage transient generated when the relay is switched OFF.

⚠️ Safety

The circuit includes an AC mains switching section. Proper electrical isolation, creepage/clearance, fuse protection, insulated terminals, and an appropriate enclosure should be used when operating with mains voltage.

Do not handle the PCB while it is connected to live AC mains.
