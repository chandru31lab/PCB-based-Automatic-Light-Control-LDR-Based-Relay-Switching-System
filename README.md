# PCB-based-Automatic-Light-Control-LDR-Based-Relay-Switching-System
EasyEDA-designed PCB ,automatic light control system using an LDR, LM358 comparator, BC547 transistor, and 5V relay to detect ambient light and automatically control an AC bulb. Includes custom PCB design, schematic, routing, 3D model, hardware assembly, and testing.
